# 萍水相逢

需求已确认，功能代码已落地；仅做源码功能复核，未运行构建、测试、迁移、设备或供应商验证。

主探索页增加独立入口。首次进入选择性别和性格喜好；深色封面卡片上下堆叠、左右滑动。卡片显示名称、简介、礼物和 Chat。底部导航为探索、特殊玫瑰色加号、聊天。加号创建用户私有角色，填写人设并上传角色封面；历史会话留在模块内。

底部使用与主导航相同的 AdaptiveGlass／LiquidGlassSettings 实现悬浮液态玻璃 Dock。中央加号使用独立玫瑰渐变、呼吸光晕、星光和点击旋转／缩放，后台与 TickerMode 禁用时暂停，减少动态效果时保留静态样式。

每个角色配置 1–3 张展示图，第一张为封面。Admin 和自定义创建均支持；服务端与数据库限制数量并保持封面一致。卡片上方滑动切图，下方滑动切角色，图片选择条可点击。兼容只传 cover_url 的旧客户端；迁移通过触发器兼容旧 Backend 的单封面写入。

四个默认可编辑角色：东方男性陆予、西方男性 Noah、东方女性林晗、西方女性 Ella。每人当前生成一张封面，采用统一暖色夜间时装摄影风格；全部为原创成年角色。女性露肤礼服生成被图片工具拒绝，最终采用红色／象牙白时装套装。PNG 已复制到 backend/internal/encounterart/images，并随 Backend 打包，通过公开的白名单图片接口展示，不依赖生成工具缓存目录。

Admin 新增独立角色管理，支持封面／头像上传与地址、人设、性格、性别、简介、排序、启用。名称打开详情，编辑使用弹窗，More 仅图标，启停使用 Switch。禁用不删除历史或撤销已确认订单。

角色、用户偏好、会话、请求、消息采用独立表，不写 companions，不进入生活事件、记忆扫描或主动触达队列。只回应用户消息或用户主动送礼。自定义封面使用已验证且属于当前用户的图片；公开配置角色由 Admin 管理。

角色资料增加年龄（18–100）、最多 8 个标签、性格、描述、真实粉丝数；头像与封面分别配置，自定义创建分别上传。聊天和列表只读取 avatar_url，没有头像时用占位，不用 cover_url 代替。卡片名称和聊天标题可打开完整资料页。

关注以 user_id／character_id 唯一关系记录，支持取消，幂等更新目标状态，粉丝数量从真实关系计数。禁用后仍允许已有用户取消关注。分享打开系统分享面板，包含角色封面和公开资料；公开角色附带可访问的 Backend 分享预览链接。私有角色不生成公开链接，不暴露人设提示词或聊天记录。分享外部封面下载不附带 Vita 凭据。

投诉必须选择原因并填写 10–2000 字说明，联系方式选填。请求键绑定完整内容，重复提交不创建多条。Admin 角色投诉页查看角色、提交者、原因、说明、联系信息、状态与处理说明；只在详情弹窗内处理，确认有效／不予采纳／待处理，说明必填。Admin 可查看私有角色资料与其实际引用的图片，不能通过此图片接口读取其他私人素材。

推荐由 Backend 排序，App 保留返回顺序。性别按保存的喜好筛选，匹配性格或标签加 60；本人尚未被驳回的投诉减 1000；全局每个不同提交者的有效投诉减 15，上限 5 人。待处理投诉不影响其他用户，同一人的多条有效投诉全局只计一次；驳回后对应处罚移除，重新请求探索列表即生效。这是降权，不是永久屏蔽；仅有一个符合性别的角色时仍能看到该角色。

照片、礼物沿用现有商品价格与订阅门槛。视频新增专用隐藏商品，不出现在旧客户端商品目录；价格、模型、5／10 秒时长和启用状态在本模块 Admin 视频配置弹窗管理。视频同样要求订阅和金币，初始关闭，没有默认可购买价格。

视频初版支持项目已有 KIE 供应商协议与 kling/v2-1-master-image-to-video 适配器。服务地址、凭据、远端模型在已有模型管理配置；未实现其他供应商协议。启用和扣费前均校验模型可用性，使用角色封面作为身份参考。协议来源：https://docs.kie.ai/market/kling/v2-1-master-image-to-video 。

媒体由角色生成。文本回复返回明确的媒体意图；用户明确请求照片或视频时，客户端打开相应付费流程。先展示商品；订阅或余额不足分别引导订阅、充值，返回后必须重新操作和确认。金币充足时收集场景、服装、动作等需求，再展示商品、需求、价格、余额及退款说明，二次确认后才预扣。

幂等键绑定用户所有的会话、商品、需求和报价；同一会话只允许一个正在处理的请求。重复成功请求返回原结果，处理中的请求不再生成或扣费，失败后的新操作需要新键。价格变化拒绝扣费。生成结果下载、验证、存入项目存储后，消息交付、订单完成和预扣结算使用同一事务；失败独立上下文退款，退款无法确认时不报告退款成功。

断网不终止已接收的请求；重新进入会话恢复正在处理的请求。前台最多每 5 秒查询一次，共 60 次，后台不查询，页面销毁取消计时器。单次生成处理最多 5 分钟；进程中断后的陈旧预扣由现有 credits 恢复流程退款，超过 10 分钟的对应请求在重试时恢复为失败，不重提原生成任务。

视频下载限制 64 MiB，检查 MP4 文件标识；存储后通过拥有者鉴权的专用 Range 接口播放。App 新增 video_player 依赖，依赖解析和原生插件集成尚未执行，需要 App 验证时先获取依赖。

上线顺序保持：迁移 → Backend、Admin、Webapp → App。新表、新接口和视频存储类型扩展兼容旧客户端；Webapp 没有新增界面。

最快验收：Admin 新建两种性别／性格的角色 → App 选择喜好、滑卡、送礼和聊天 → 加号创建私有角色 → 配置照片模型及 KIE 视频模型，设置视频金币并开启 → 订阅用户填写需求、确认消费、观察预扣和结果。另验证重复提交、断网回访、余额不足、价格变更、角色禁用、跨用户访问、失败退款，以及角色不产生事件或主动触达。
