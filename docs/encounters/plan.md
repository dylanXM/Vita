# 实现计划

1. 已确认角色生成媒体、加号创建自定义角色、沿用照片／礼物价格及订阅门槛；新增可配置视频商品。
2. 增量迁移独立角色、偏好、会话、消息与订单表；添加索引、归属与幂等约束。
3. Backend 添加 Admin 配置接口、偏好筛选、会话及被动回复接口。复用模型路由与用量记录，不调用生活事件或主动触达服务。
4. Admin 添加独立菜单、角色列表、详情与编辑弹窗；图片配置复用 AdminImageInput，状态复用 Switch，操作复用 ListActions。
5. App 添加探索入口、偏好选择、深色堆叠卡片与三项导航、模块聊天，保持固定卡片尺寸和历史阅读位置。
6. 按已确认规则接入礼物与媒体需求、报价、预扣、生成、存储、事务交付及退款；订单查询用于恢复，避免无界轮询。
7. 更新 Admin 两种语言与 App 八种语言。仅做用户授权的源码功能检查，不执行测试、构建、静态检查或其他 CPU 密集命令；设备与供应商实际验证单独说明。
8. 复核兼容部署顺序、授权边界、幂等键参数绑定、禁用角色、错误恢复与布局边界，再给出文件清单和最快验证路径。
