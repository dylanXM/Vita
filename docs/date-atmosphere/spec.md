# 第一视角浪漫约会

咖啡厅、晚餐、舞会、电影约会采用统一温暖写实环境。用现有人物参考生成 TA 与环境同光线、同透视的完整图片，不要求用户上传形象。生成图片展示后隐藏拼贴头像和独立道具。环境占主要空间，TA 的最新回应以短字幕出现，完整会话按需展开。

用户在画面中点击交互点，选择饮品／菜品、举杯／共舞或电影氛围／暂停交流。成功发送的操作保存到约会消息；画面状态由已保存操作恢复。失败不改变画面，不额外收费。TA 回应必须承接真实操作。

Admin 按约会商品配置背景、环境音地址；默认正式背景随 App 打包。无新增轮询，兼容旧 App。音频自愿开启，离开场景停止；减少动态效果时关闭环境动效。

验收：四场景一致美术、人物融入环境、操作有实际反馈、回访状态保留、普通聊天共享记忆、键盘与 RTL 可用。现有电影约会保留，另增舞会商品。

图片包含在约会价格内，暂不包含视频。入场、相处、告别各保存一张；同一事件同一节点复用，不按聊天轮次生成。独立持久化后台任务每次处理一个，失败最多三次、间隔十分钟；不阻塞入场、聊天和记忆任务，不新增 App 轮询。进度不得因图片完成顺序倒退。付款前说明包含内容，此刻卡片约会左侧提供礼物入口。

电影约会提供虚拟影院氛围和投影光效，不播放真实影片，不声称已观看真实电影。
