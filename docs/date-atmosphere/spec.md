# 第一视角浪漫约会

咖啡厅、晚餐、舞会、电影约会采用统一温暖写实环境，无人物头像、无人物上传、无几何插画作为正式背景。环境占主要空间，TA 的最新回应以短字幕出现，完整会话按需展开。

用户在画面中点击交互点，选择饮品／菜品、举杯／共舞或电影氛围／暂停交流。成功发送的操作保存到约会消息；画面状态由已保存操作恢复。失败不改变画面，不额外收费。TA 回应必须承接真实操作。

Admin 按约会商品配置背景、环境音地址；默认正式背景随 App 打包。无新增轮询，兼容旧 App。音频自愿开启，离开场景停止；减少动态效果时关闭环境动效。

验收：三场景一致美术、无人物形象、操作有实际反馈、回访状态保留、普通聊天共享记忆、键盘与 RTL 可用。现有电影约会保留，另增舞会商品。

电影约会提供虚拟影院氛围和投影光效，不播放真实影片，不声称已观看真实电影。
