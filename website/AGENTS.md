# Marketing website guide

- Keep the Vita marketing identity consistent across routes: typography,
  spacing, color, imagery and motion must come from shared tokens/components.
- Marketing claims must match shipped product behavior. Do not describe reserved
  video, calling or model-routing capabilities as available before activation.
- Preserve responsive layouts, semantic HTML, keyboard access, reduced-motion
  behavior and metadata needed for sharing and search.
- Run typecheck, lint and the production Vite build after changes.
